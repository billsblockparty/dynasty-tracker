# Team logos (optional)

Drop one image per NFL team in this folder and the Matchups, Playoffs and Custom rows will show it
next to the player's name instead of the coloured team badge. Teams without a file keep the badge.

- Name each file with the team code the site uses: `ARI ATL BAL BUF CAR CHI CIN CLE DAL DEN DET GB HOU IND JAX KC
  LAC LAR LV MIA MIN NE NO NYG NYJ PHI PIT SEA SF TB TEN WAS` — for example `DET.svg` or `KC.png`.
- SVG, PNG or WEBP. PNGs at least 64×64 with a transparent background.
- Upload on GitHub (Add file → Upload files, into `pipeline/logos/`) and commit. The site rebuilds within a minute or two.
